# Mon book de formation — POEI Victoria's Secret

Suivi personnel de la formation POEI Victoria's Secret (Montpellier, 31 août – 15 octobre 2026) : une page par jour, avec pistes de réflexion, notes libres et deux jauges (énergie / aisance) pour repérer au fil de l'eau où se situent les vrais points forts.

**En ligne :** https://baike-33.github.io/book-formation-vs/

## Comment ça marche

- Toutes les notes sont saisies directement dans la page et sauvegardées automatiquement dans le navigateur (IndexedDB, avec repli sur localStorage) — rien n'est envoyé nulle part.
- **Exporter mon book** télécharge une copie HTML autonome, notes incluses, ouvrable hors-ligne sur n'importe quel appareil.
- **Sauvegarder mes notes (fichier)** / **Importer une sauvegarde** permettent de déplacer les notes (format JSON) d'un navigateur à l'autre.

Un seul fichier `index.html`, aucune dépendance de build.

## Publier une mise à jour

Double-clique sur `PUBLIER.command` (non versionné, reste en local) après avoir modifié `index.html` et fait un commit.
